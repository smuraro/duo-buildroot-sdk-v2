# Milk-V Duo series buildroot SDK V2

```
./build.sh lunch
```

For more detailed documentation, please refer to: [https://milkv.io/docs/duo/getting-started/buildroot-sdk](https://milkv.io/docs/duo/getting-started/buildroot-sdk)

The project's main differentiators are:
1) Node-RED functionality (recamera) ported to the Milk-V (GC2083 camera).
2) Functional Python with the tdl_sdk. Everything is available for RISC-V in the emmc and sd versions, using musl.
3) Complete book in Portuguese with various tips and important information for those who want to venture into using Milk-V boards.
4) The tdl_sdk allows the use of Yolo 11 and Yolo 26 models.

It does not compile for the ARM version.
